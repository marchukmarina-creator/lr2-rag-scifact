# Лабораторная работа 2 — SciFact RAG

Проект строит базовый RAG для проверки научных утверждений. Он фиксирует разбиение SciFact, кодирует 5183 аннотации `BAAI/bge-small-en-v1.5`, собирает контекст в бюджете 2048 токенов и вызывает `Qwen/Qwen3-4B-Instruct-2507` через локальный vLLM.

## Быстрый запуск в Colab

1. Включите GPU T4.
2. Откройте `notebooks/LR2_clean.ipynb` в Colab.
3. Выполните первую ячейку и дождитесь `СЕРВЕР ГОТОВ`.
4. Выполните вторую ячейку. Она сама выполнит подготовку данных, проверки, 420 измеряемых вызовов, анализ и скачает архив артефактов.

Holdout из 210 утверждений сохраняется для ЛР3 и в ЛР2 не используется.

## Команды каркаса

```text
python lr2.py prepare
python lr2.py check
python lr2.py run
python lr2.py analyze
python lr2.py pack
```

`run` выполняется только из чистого зафиксированного Git-репозитория. Повторный запуск не повторяет уже записанные задания: наличие любой строки с `job_id` означает, что вызов учтён, включая ошибку.

## Результаты

- `runs/lr2_final/results.jsonl` — первичные записи всех 420 вызовов;
- `data/generated/manifest.json` — источник, хеши и фиксированное разбиение;
- `index/passport.json` и `index/embeddings.npy` — паспорт и матрица индекса;
- `reports/generated/` — таблицы, графики, четыре случая и отчёт;
- `mlflow.db` — параметры, метрики и артефакты запусков.

Кодогенерация: каркас подготовлен с помощью OpenAI Codex. Численные результаты не вписаны вручную и пересчитываются из `results.jsonl`.
